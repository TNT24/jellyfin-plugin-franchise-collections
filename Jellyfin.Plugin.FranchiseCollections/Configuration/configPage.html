Franchise Collections

Groups movies into collections using the franchise data TMDb provides (e.g. "The Matrix Collection", "Shrek Collection"). Movies need TMDb metadata for this to work.

Only create a collection once you own at least this many movies from the franchise.
Runs a sync a couple of minutes after the library changes. A daily sync also runs from Scheduled Tasks.
Movies you added to a collection by hand are never removed.
One collection name per line, e.g. "James Bond Collection". These are never created or changed.
