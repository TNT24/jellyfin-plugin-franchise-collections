Franchise Collections

Groups movies into collections using the franchise data from TMDb, such as "The Matrix Collection" or "Shrek Collection". Movies need TMDb metadata for this to work.

Changes are saved automatically.

Collections

A collection is only created once you have at least this many movies from the franchise.
Only movies in the ticked libraries are grouped. Leave them all unticked to use every library.

Appearance

Applied to every franchise collection on each sync.
Builds a poster from up to four of the collection's movie posters, in release order. "Always" also replaces posters you picked yourself. Posters made this way are updated when movies are added.

Updates

Runs a sync a couple of minutes after the library changes. A daily sync also runs from Scheduled Tasks.
Movies you added to a collection by hand are never removed.

Excluded franchises

The plugin never creates, changes or deletes these collections. Use it for a franchise you don't want a collection for, or to keep a collection you made yourself when you run Sync and override.

Run now

Creates missing collections and adds new movies to existing ones.
Makes your collections match TMDb exactly. Movies you added by hand are removed, a collection with the same name as a franchise is taken over, franchise collections with fewer movies than the minimum are deleted, and every other collection is deleted, including ones you made yourself. The movies are kept. To keep a collection, add its name to Excluded franchises or lock it ("Lock this item" in its metadata editor) first. With libraries ticked, collections holding movies from other libraries, and those movies, are left alone.
